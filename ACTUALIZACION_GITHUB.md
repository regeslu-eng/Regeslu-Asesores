# Actualización incremental REGESLU

**Posicionamiento**: REGESLU = soluciones digitales y soluciones empresariales. Otros rubros = red de aliados estratégicos externos, sin ejecución propia.

## Para actualizar sin borrar el proyecto

1. Elimina del repositorio antiguo, si existen: `proyectos/index.html`, `servicios/seo-google/index.html` y el directorio completo `images/clientes/`.
2. Sube todos los archivos incluidos en el paquete **SOLO_CAMBIOS**, respetando subcarpetas, mediante commit a tu rama de producción.
3. Verifica que `aliados-estrategicos/index.html` sea una ruta nueva y que `servicios/index.html` mantenga el enfoque principal de REGESLU.
4. Confirma el despliegue en Vercel y revisa enlaces, formulario y sitemap.

**Conservar**: logotipo, iconos, assets base y repositorio GitHub. El ZIP no elimina archivos anteriores por sí mismo.
