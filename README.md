# REGESLU.COM — Soluciones Digitales & Empresariales — Versión final

Versión premium/minimalista del sitio de REGESLU, preparada para publicar en GitHub + Vercel y conectar al dominio `regeslu.com`.

## Mejoras de esta versión

- Diseño corporativo minimalista con mayor jerarquía visual.
- Animaciones suaves por scroll con `IntersectionObserver`.
- Barra de progreso de navegación.
- Header translúcido con efecto blur.
- Hero interactivo con efecto 3D sutil en escritorio.
- Tarjetas con microinteracciones y spotlight.
- Logos de clientes en monocromo con color al pasar el cursor.
- Diagrama REGESLU animado.
- Línea de proceso animada.
- FAQ con interacción más limpia.
- Respeta `prefers-reduced-motion` para accesibilidad.
- Diseño responsive para escritorio, tablet y celular.
- Sin frameworks ni dependencias de JavaScript.

## Publicación en Vercel

1. Sube esta carpeta completa a GitHub.
2. En Vercel selecciona **Add New → Project**.
3. Importa el repositorio.
4. No requiere framework ni comando de build.
5. Publica y después agrega `regeslu.com` en **Settings → Domains**.
